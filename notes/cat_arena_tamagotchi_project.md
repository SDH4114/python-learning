# Cat Arena Tamagotchi

## Концепт проекта

**Cat Arena Tamagotchi** - это консольная Python-игра, где игрок собирает коллекцию котов, заботится о них, развивает их характеристики и участвует в пошаговых подпольных кошачьих битвах.

Игра смешивает два настроения:

- милый тамагочи
- тёмный подпольный кошачий бойцовский клуб

Баланс проекта:

```text
40% уход за котами
60% битвы и развитие
```

Главная идея:

```text
Ты не просто нажимаешь “attack”. Ты выращиваешь, тренируешь, кормишь, лечишь и собираешь команду котов, которые потом дерутся на подпольных аренах.
```

---

## Игровой Образ

Ты начинаешь как обычный человек, который нашёл первого кота. Сначала это почти обычный питомец: его надо кормить, лечить, развлекать и укладывать спать.

Но потом открывается другой слой мира: ночные подвалы, дворовые арены, странные торговцы, редкие породы, нелегальные турниры и легендарные коты-бойцы.

Тон игры:

```text
мило снаружи, жёстко внутри
```

Примеры атмосферы:

- днём кот спит на подушке
- вечером просит рыбу
- ночью выходит на бой в подвале старой пекарни
- после победы приносит монеты и царапины
- после поражения требует лечения и отдых

## Главные Системы Игры

### 1. Система Котов

Каждый кот - отдельный объект со своими характеристиками.

У кота есть:

- имя
- порода
- уровень
- опыт
- здоровье
- голод
- энергия
- настроение
- атака
- защита
- скорость
- шанс критического удара
- редкость
- статус

Пример статусов:

```text
normal
hungry
tired
injured
angry
sleeping
ready_to_fight
```

---

### 2. Система Ухода

Уход влияет на боевую эффективность.

Действия:

- покормить кота
- поиграть с котом
- уложить спать
- вылечить
- потренировать
- проверить состояние

Пример логики:

```text
если кот голодный -> меньше атака
если кот устал -> меньше скорость
если кот счастлив -> больше шанс критического удара
если кот ранен -> нельзя идти в бой
```

Так уход становится не декоративным, а важным для битв.

---

### 3. Система Боя

Бой пошаговый, как в Pokémon.

Игрок выбирает действие каждый ход.

Пример меню боя:

```text
Battle Menu

1. Attack
2. Defend
3. Skill
4. Use item
5. Switch cat
6. Run
```

Варианты действий:

- обычная атака
- защита
- специальный навык
- использование предмета
- смена кота
- попытка сбежать

Бой должен быть отдельной системой, а не частью класса `Cat`.

---

### 4. Коллекция Котов

Игрок собирает много котов.

Можно иметь:

- активного кота
- запасных котов
- коллекцию всех найденных котов

Пример:

```text
Active cat: Shadow

Collection:
1. Shadow - Street Cat - Level 3
2. Milk - Fat Cat - Level 2
3. Ghost - Ghost Cat - Level 1
```

Каждый кот должен ощущаться по-разному.

## Главное Правило Архитектуры

Не смешивать всё в одном классе.

Плохо:

```text
Cat отвечает за бой, магазин, сохранение, меню и инвентарь
```

Хорошо:

```text
Cat -> только кот
Battle -> только бой
Shop -> только магазин
Inventory -> только инвентарь
SaveManager -> только сохранение
Game -> только управление меню
```

## Формула Урона

Простая формула для первой версии:

```text
damage = attacker.attack - defender.defense // 2
```

Минимальный урон:

```text
если damage меньше 1 -> damage = 1
```

Критический удар:

```text
если выпал crit -> damage * 2
```

Защита:

```text
defend уменьшает входящий урон на 50% в следующий ход
```

## Самая Сильная Версия Идеи

Игра может стать такой:

```text
Cat Arena Tamagotchi - консольная RPG-тамагочи, где игрок собирает и выращивает котов-бойцов, заботится о них днём и выводит на подпольные арены ночью.
```

Ключевая фишка:

```text

```

Если кот голодный, уставший или несчастный, он хуже дерётся. Если кот ухоженный, счастливый и натренированный, он получает преимущество.

Это делает игру не просто боевой, а именно тамагочи-RPG.
