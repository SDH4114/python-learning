# Что Нужно Знать Для Data Science И Machine Learning

Главная идея: после базового курса Python тебе нужен не еще один абстрактный курс Python, а переход в прикладной стек **Data Science + Machine Learning**.

По твоим заметкам видно направление: Python, AI/LLM, Computer Vision, PyTorch, Pandas, математика для ML. Я смотрел материалы из `zero-to-one/study/it/materials.md`, `zero-to-one/study/it/Обзор математики.md`, `zero-to-one/study/it/Обучение-ии.md`, `zero-to-one/стажировка.md`.

## Главная Карта

1. Python для данных.
2. Математика для ML.
3. Data Science инструменты.
4. Классическое Machine Learning.
5. Deep Learning / Computer Vision / LLM.
6. Проекты в портфолио.

## 1. Что Добить В Python

После базового курса тебе надо уверенно знать:

- функции, аргументы, `*args`, `**kwargs`
- списки, словари, множества, кортежи
- list/dict comprehensions
- работа с файлами: `.txt`, `.csv`, `.json`
- исключения: `try/except`
- модули, пакеты, импорты
- ООП: классы, методы, наследование, `self`
- виртуальные окружения: `venv`, `pip`
- Jupyter Notebook
- типизация: `list[int]`, `dict[str, int]`, `Optional`, `Union`
- базовый `pytest`
- Git и GitHub

Важно: для DS/ML Python нужен не как язык сам по себе, а как инструмент для обработки данных, экспериментов и моделей.

## 2. Python-Библиотеки, Которые Нужно Знать

Сначала:

- `NumPy` - массивы, векторы, матрицы
- `Pandas` - таблицы, датасеты, очистка данных
- `Matplotlib` - графики
- `Seaborn` - красивые статистические графики
- `Jupyter` - среда для анализа

Потом:

- `Scikit-learn` - классический ML
- `PyTorch` - нейросети
- `OpenCV` - компьютерное зрение
- `HuggingFace Transformers` - LLM/NLP модели
- `FastAPI` - если хочешь выкладывать модель как API

Минимальный порядок:

```text
NumPy -> Pandas -> Matplotlib/Seaborn -> Scikit-learn -> PyTorch
```

## 3. Какие Языки Программирования Нужны

Тебе не надо учить 5 языков сразу.

Обязательное:

- **Python** - главный язык DS/ML.
- **SQL** - обязательно для работы с реальными данными.
- **Bash/Terminal basics** - запуск скриптов, окружения, файлы, Git.

Полезно позже:

- **JavaScript/TypeScript** - если хочешь делать веб-интерфейсы для моделей.
- **C++** - позже, если пойдешь в performance, computer vision, embedded, robotics.
- **R** - можно не учить сейчас. Он полезен в статистике, но Python важнее.

Твой фокус на ближайшие месяцы:

```text
Python + SQL + Git
```

## 4. Математика, Которую Надо Знать

Главные 4 базы:

- линейная алгебра
- математический анализ
- теория вероятностей и статистика
- оптимизация

### Линейная Алгебра

Нужно знать:

- векторы
- матрицы
- умножение матриц
- транспонирование
- скалярное произведение
- нормы векторов
- расстояния между векторами
- косинусное сходство
- собственные значения/векторы - позже
- SVD/PCA - позже

Зачем:

- картинки = матрицы
- эмбеддинги = векторы
- нейросети = матричные операции
- Transformer = огромная математика над векторами

### Математический Анализ

Нужно знать:

- функция
- производная
- частная производная
- градиент
- минимум/максимум функции
- цепное правило
- понятие loss function

Зачем:

- модель учится через уменьшение ошибки
- backpropagation = производные
- gradient descent = движение по градиенту

### Вероятность И Статистика

Нужно знать:

- среднее, медиана, дисперсия, стандартное отклонение
- распределения
- нормальное распределение
- вероятность события
- условная вероятность
- корреляция
- выборка
- гипотезы
- p-value - позже
- доверительные интервалы - позже

Зачем:

- анализ данных
- оценка качества модели
- A/B тесты
- понимание шума в данных

### Оптимизация

Нужно знать:

- gradient descent
- learning rate
- loss function
- overfitting / underfitting
- regularization
- train/test split
- validation

Зачем:

- ML = подбор параметров так, чтобы ошибка была меньше.

## 5. Data Science База

Ты должен уметь:

- загрузить датасет
- понять структуру данных
- найти пропуски
- почистить данные
- построить графики
- найти зависимости
- подготовить признаки
- обучить простую модель
- оценить качество
- объяснить результат

Ключевые темы:

- EDA: Exploratory Data Analysis
- feature engineering
- train/test split
- метрики качества
- классификация
- регрессия
- кластеризация
- работа с CSV/JSON/SQL

## 6. Machine Learning База

Начни с классического ML, не прыгай сразу в LLM.

Нужно знать модели:

- Linear Regression
- Logistic Regression
- KNN
- Decision Tree
- Random Forest
- Gradient Boosting
- K-Means
- PCA
- SVM - позже

Метрики:

- accuracy
- precision
- recall
- F1-score
- confusion matrix
- MAE
- MSE
- RMSE
- ROC-AUC - позже

Главная цель: не просто запускать `model.fit()`, а понимать:

```text
какие данные -> какая задача -> какая модель -> какая метрика -> какой результат
```
