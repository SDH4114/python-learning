# Adventurer Market

Идея мини-проекта: **магазин авантюриста с квестами**.

Это развитие текущего `shop.py`, но сильнее и интереснее. Проект хорошо подходит под уже изученные темы Python.

## Что уже изучено

- `print`, `sep`, `end`, комментарии
- числа, арифметика, `min`, `max`, `abs`, `pow`, `round`
- типы: `int`, `float`, `str`, `bool`
- преобразования типов: `str()`, `int()`, `float()`
- строки: индексы, срезы, `upper`, `lower`, `capitalize`, `count`, `find`, `split`, `join`
- списки: `append`, `insert`, `extend`, `sort`, `reverse`, `pop`, `remove`, `clear`, `count`, `len`
- кортежи и неизменяемость
- множества, `set`, `frozenset`, удаление дублей
- словари, вложенные словари, `keys`, `values`, `items`, `get`, `update`, `pop`
- `if / elif / else`, логика `and`, `or`, `in`
- циклы `for`, `while`, `range`, `break`, `continue`
- функции, `return`, `lambda`
- работа с файлами через `open`, режимы `w`, `a`, `r`
- ввод пользователя через `input`
- мини-проекты: калькулятор и консольный магазин

## Суть проекта

Пользователь заходит в аккаунт, покупает предметы, складывает их в сумку, выполняет квесты и получает награды.

Пример стартового меню:

```text
Добро пожаловать в Adventurer Market

1. Войти
2. Зарегистрироваться
3. Выйти
```

После входа:

```text
1. Магазин
2. Сумка
3. Квесты
4. Профиль
5. Сохранить
6. Выйти
```

## Что добавить

- Пользователи хранятся в словаре.
- Товары хранятся в словаре.
- Сумка игрока хранится в словаре.
- Квесты хранятся в словаре.
- Купленные предметы можно использовать для выполнения квестов.
- Данные можно сохранять в файл `data/save.txt`.
- Можно сделать промокоды через `set`, чтобы один промокод нельзя было использовать дважды.

## Пример данных

```python
products = {
    "Iron Sword": 50,
    "Health Potion": 15,
    "Magic Mushroom": 33,
    "Obsidian Carrot": 17,
}

quests = {
    "Goblin Hunt": {
        "need": {"Iron Sword": 1, "Health Potion": 2},
        "reward": 100,
    },
    "Witch Soup": {
        "need": {"Magic Mushroom": 2, "Obsidian Carrot": 1},
        "reward": 80,
    },
}
```

## Минимальный план проекта

1. Создать стартовые данные: `users`, `products`, `quests`.
2. Сделать регистрацию и вход.
3. Сделать главное меню.
4. Сделать магазин: показать товары, купить товар.
5. Сделать сумку: показать предметы, удалить предмет.
6. Сделать квесты: проверить, хватает ли предметов.
7. Добавить награду: деньги игроку.
8. Добавить сохранение в файл.
9. Добавить загрузку из файла.
10. Добавить промокоды или достижения.

## Более креативная версия

Можно сделать не обычный магазин, а **магазин между мирами**.

Идеи:

- обычные товары: хлеб, вода, яблоко
- магические товары: лунная соль, кофе бездны, мед призрака
- покупатели и аккаунты: маг, вор, рыцарь
- квесты: "собери суп странника", "подкупи гнома", "спаси призрака"
- ошибки пользователя можно оформлять как реплики продавца

Так это будет не просто учебный проект, а маленькая консольная игра.
